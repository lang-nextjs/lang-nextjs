# @deepagents-nextjs/rungs

The rung manifest as typed data. Generated from `rungs.json` — the single authority on what a rung is.

This is where a forker learns the vocabulary: what a rung's **shape**, **state** and **target** mean, and which rungs a fork keeps when it ejects.

## Installation

Workspace-internal — it is not published to npm. Every package in this repo can depend on it as a workspace link:

```bash
pnpm add '@deepagents-nextjs/rungs@workspace:*' --filter <your-package>
```

It is classified `shared`: it survives every eject, at every rung.

## Quick Start

Which rungs does a fork keep, and where does each one point?

```typescript
import { retainedRungs, rungHref } from "@deepagents-nextjs/rungs";

const kept = retainedRungs("open-swe");
const links = kept.map((rung) => ({
  id: rung.id,
  href: rungHref(rung, process.env),
}));
```

Routing on a rung's shape, so a new shape is a compile error rather than a blank screen:

```typescript
import { assertNever, type Rung } from "@deepagents-nextjs/rungs";

function surfaceFor(rung: Rung): string {
  switch (rung.shape) {
    case "conversation":
      return "composer";
    case "run":
      return "departure card";
    default:
      return assertNever(rung.shape);
  }
}
```

## API Reference

### Data

| Export        | Type                             | Description                  |
| ------------- | -------------------------------- | ---------------------------- |
| `RUNGS`       | `readonly Rung[]`                | Every rung, in ordinal order |
| `RUNG_BY_ID`  | `Readonly<Record<RungId, Rung>>` | The same rungs, keyed by id  |
| `RUNG_IDS`    | `readonly RungId[]`              | Ids only, in ordinal order   |
| `RUNG_SHAPES` | `readonly RungShape[]`           | The two interaction shapes   |

### `retainedRungs(target)`

The rungs a fork retains when ejected to `target` — the transitive closure of `requires`, lowest ordinal first. Each rung is a superset of the concerns below it, so ejecting never leaves a bare single rung.

### `rungHref(rung, env?)`

Resolves a rung's URL. The substitution rule lives here and only here: the literal `[param]` in `target.route` is replaced by `target.value`.

**Returns `null` when there is nothing to link to** — a `planned` rung — so callers render it as declared-but-absent rather than offering a dead link.

### `matrixCells()`

Every (rung, runtime, topology) cell the CI matrix derives from. An empty `topologies` array means **one cell with no topology axis, not zero cells**; that rule is encoded here deliberately so callers do not each re-derive it. Filter on `state` if you want only runnable cells.

### `assertNever(x)`

Exhaustiveness helper. `default: return assertNever(shape)` fails to compile when a new shape is added to the manifest.

## The vocabulary

| Field       | Meaning                                                                                                                                                                                         |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `shape`     | `conversation` or `run`. How you interact with the rung. **A shape is not a stream topology** — `run` does not mean "one run"; Open SWE registers three graphs that do not share a run.         |
| `state`     | `implemented`, `external-required`, or `planned`. A `planned` rung has no files and no target.                                                                                                  |
| `target`    | A discriminated union, because "one rung = one route" cannot express the ladder: rungs 1–3 share one surface selected by a param, rung 4 is a whole app on a different origin, rung 5 has none. |
| `requires`  | The rungs this one builds on. Drives `retainedRungs`.                                                                                                                                           |
| `languages` | Which language planes hold files this rung **owns** — drives the 8-job severability matrix.                                                                                                     |
| `runtimes`  | Which backends **serve** this rung. Not the same as `languages`: rung 1 owns TS and Python files but is served by django and fastapi only.                                                      |

## What is deliberately not here

- **`owns`** — the file globs live in `rungs.json` and are **not** projected into these types. Read the manifest for those.
- **A `route` target variant** — no rung has its own in-app route, and a variant nothing exercises rots while reading to a reviewer as "handled".

## Regenerating

`src/generated.ts` is generated by `scripts/gen-rung-types.mjs` from `rungs.json`. Do not edit it by hand; run the generator and commit the result. CI fails if the two drift.
