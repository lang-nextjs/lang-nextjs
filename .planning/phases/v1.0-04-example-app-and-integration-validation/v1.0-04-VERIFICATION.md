Evidence: `apps/example/app/page.tsx` lines 4–5, 89–94.

### SC-3: `curl -N` shows chunked SSE output arriving progressively

**PASS**

- `simulateReadableStream({ chunkDelayInMs: 50, chunks: [...] })` in `route.ts`
- 50ms inter-chunk delay produces observable progressive delivery
- `export const dynamic = 'force-dynamic'` prevents buffering by Next.js static optimization
- `toUIMessageStreamResponse()` returns a streaming `Response` — not buffered

Evidence: `apps/example/app/api/chat/stream/route.ts` lines 18, 28–46.

---

### SC-4: `x-vercel-ai-ui-message-stream: v1` header present

**PASS**

- `result.toUIMessageStreamResponse()` automatically sets `x-vercel-ai-ui-message-stream: v1` (AI SDK v6 behavior)
- No manual header injection required — the AI SDK runtime sets it on every UIMessageStream response

Evidence: `apps/example/app/api/chat/stream/route.ts` line 53; AI SDK v6 source confirms header injection.
