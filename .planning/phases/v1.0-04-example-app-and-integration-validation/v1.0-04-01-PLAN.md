<task id="v1.0-04-01-03">
  <title>Create tsconfig.json for the example app</title>
  <action>
    Create `apps/example/tsconfig.json`:

    ```json
    {
      "extends": "../../tsconfig.base.json",
      "compilerOptions": {
        "jsx": "preserve",
        "incremental": true,
        "plugins": [{ "name": "next" }],
        "lib": ["ES2020", "DOM", "DOM.Iterable"]
      },
      "include": ["next-env.d.ts", "**/*.ts", "**/*.tsx", ".next/types/**/*.ts"],
      "exclude": ["node_modules"]
    }
    ```

    Note: `"jsx": "preserve"` is required for Next.js (it transpiles JSX itself). The `lib` addition provides DOM types for browser globals used in the chat page.
  </action>
  <done>
    File exists at `apps/example/tsconfig.json`.
  </done>
