# Research: Phase v1.0-04 — Example App and Integration Validation

## Summary

Build the `apps/example/` Next.js App Router application with a mock SSE route that speaks the AI SDK v6 `UIMessageStream` protocol and a chat UI using `useDeepAgentsChat()`. No real DeepAgents backend is needed. The example proves the full library stack works end-to-end.

## Current State

`apps/example/package.json` exists as a placeholder with stub `build`/`dev`/`test` scripts and workspace deps on `@deepagents-nextjs/server` and `@deepagents-nextjs/react`. No Next.js is installed, no `next.config.ts`, no `app/` directory.

## Key Finding: The Mock Route is NOT a Proxy

The success criteria require that `curl -N` shows progressive SSE output and the `x-vercel-ai-ui-message-stream: v1` header is present. This means the mock route must speak the **AI SDK v6 UIMessageStream protocol** — the same format `useChat` + `DefaultChatTransport` consumes. It must NOT be a raw SSE stream.

The correct approach is:
```typescript
import { streamText } from 'ai'
import { MockLanguageModelV3 } from 'ai/test'

export async function POST() {
  const result = streamText({
    model: new MockLanguageModelV3({ doStream: ... }),
    prompt: 'ignored',
  })
  return result.toUIMessageStreamResponse()
}
```

`toUIMessageStreamResponse()` automatically sets:
- `Content-Type: text/event-stream`
- `x-vercel-ai-ui-message-stream: v1`
- Chunked transfer encoding

### `streamText` + mock model

```typescript
import { streamText, simulateReadableStream } from 'ai'
import { MockLanguageModelV3 } from 'ai/test'

const model = new MockLanguageModelV3({
  doStream: async () => ({
    stream: simulateReadableStream({
      chunkDelayInMs: 50,
      chunks: [
        { type: 'text-start', id: 't1' },
        { type: 'text-delta', id: 't1', textDelta: 'Hello from ' },
        { type: 'text-delta', id: 't1', textDelta: 'the mock!' },
        { type: 'text-end', id: 't1' },
        // tool-call sequence
        {
          type: 'tool-call',
          toolCallId: 'tc1',
          toolName: 'lookup',
          input: { query: 'test' },
        },
        {
          type: 'tool-result',
          toolCallId: 'tc1',
          result: { answer: 'mocked result' },
        },
        { type: 'finish', finishReason: 'stop', usage: { promptTokens: 0, completionTokens: 0 } },
      ],
    }),
    rawCall: { rawPrompt: null, rawSettings: {} },
  }),
})
```

**Note on tool-call visibility in the UI:** For `ToolCallMessage` to appear via `useDeepAgentsChat`, the tool parts must survive the `partsToMessages()` converter. The converter handles `dynamic-tool` and `tool-{name}` part types from the `UIMessage.parts[]` array. The AI SDK v6 `streamText` + `toUIMessageStreamResponse()` produces `tool-{toolName}` parts on the client side automatically when tools are declared in the `tools` option.

result.toUIMessageStreamResponse()

## Chat UI Implementation Pattern

```tsx
'use client'

import { useDeepAgentsChat } from '@deepagents-nextjs/react'

export default function ChatPage() {
  const { messages, sendMessage, status } = useDeepAgentsChat({
    sessionId: 'example-session',
    endpoint: '/api/chat/stream',
  })

  return (
    <main className="flex flex-col h-screen">
      <div className="flex-1 overflow-y-auto p-4 space-y-4">
        {messages.map((msg) => {
          if (msg.type === 'user') return <UserBubble key={msg.id} msg={msg} />
          if (msg.type === 'ai') return <AIBubble key={msg.id} msg={msg} />
          if (msg.type === 'tool-call') return <ToolCallCard key={msg.id} msg={msg} />
          return null
        })}
      </div>
      <form onSubmit={(e) => { e.preventDefault(); sendMessage(input); setInput('') }}>
        <input value={input} onChange={(e) => setInput(e.target.value)} />
        <button type="submit" disabled={status !== 'idle'}>Send</button>
      </form>
    </main>
  )
}
```
