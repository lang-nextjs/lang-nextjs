## Accomplishments

- Created `.github/workflows/e2e.yml` with two independent sibling jobs: `e2e-django` and `e2e-fastapi`
- Both jobs skip on external PRs via `head.repo.full_name == github.repository` — no false failures from missing secrets
- `ANTHROPIC_API_KEY` injected from GitHub Actions secrets in both compose stack startup steps
- Playwright failure reports uploaded as artifacts (`playwright-report-django` / `playwright-report-fastapi`) on job failure
- `docker compose down -v` runs on `always()` to clean volumes after each run regardless of outcome

## Decisions Made

- External PR skip uses `head.repo.full_name == github.repository` — the standard pattern for trusted-contributor-only jobs without `environment:` protection rules (which require paid plans for private repos)
- `timeout 120` for health wait — gives 2 minutes for Docker image pull and LLM model loading
- `docker compose down -v` on `always()` — cleans volumes even on test failure to avoid CI disk pressure between runs
- `pnpm exec playwright install chromium --with-deps` — installs only Chromium, matching the single project in `playwright.config.ts`
- `pnpm build` runs before E2E — ensures `packages/server` and `packages/react` are built before `apps/example` imports workspace packages
- Jobs are sibling jobs (not sequential) — a Django failure does not cancel the FastAPI job
