  <behavior>
Accepts SvelteKit `RequestEvent` and `SvelteKitHandlerOptions`, returns an async POST handler that:
1. Calls `assertNodeRuntime()` — throws if `process.versions?.node` is undefined
2. Reads `event.request.arrayBuffer()` for the body
3. Forwards request headers to backend fetch (excluding host, content-length)
4. If `getToken` is provided and returns a string, injects `Authorization: Bearer {token}` header
5. Proxies via `fetch(backendUrl, { method: 'POST', headers, body })`
6. Pipes the response body through `SseFrameAccumulator` + transform pipeline (adapter.transforms then options.transforms)
7. Returns `new Response(transformedStream, { headers: { 'Content-Type': 'text/event-stream', ... } })`

Factory signature (matches RESEARCH.md Pattern 1):
```typescript
export function createDeepAgentsHandler(options: SvelteKitHandlerOptions): (event: RequestEvent) => Promise<Response>
```
Consumer usage in +server.ts:
```typescript
export const POST = createDeepAgentsHandler({ backendUrl: process.env.BACKEND_URL! });
```

Test cases (in handler.test.ts):
- `handler returns Response with content-type: text/event-stream` — mock fetch returns SSE body, assert response Content-Type header
