## Decisions Made

- **queueMicrotask idle guard:** The `writable` StartStopNotifier runs synchronously when the first subscriber calls `subscribe()`. Without `queueMicrotask`, the initial `set({ status: 'loading' })` fires before the subscriber's callback has received the initial value, overwriting idle immediately. Wrapping in `queueMicrotask` defers to the next microtask checkpoint so the subscriber first sees `{ status: 'idle' }`.
- **No FSM library:** 5-state machine (idle → loading → streaming → done/error) is simple enough for inline conditionals per plan spec. State-machine-bias rule threshold not reached.
- **AbortError ignored:** `controller.abort()` throws `AbortError` on the pending `fetch()` or `reader.read()`. This is expected cleanup, not a failure — silently returning prevents a spurious `status=error` update on normal unsubscribe.
