## Decisions Made

- `assertNodeRuntime()` inside handler body not module top-level — deferring the Node check to call time means the module can be safely imported (e.g., during build or in test environments) without crashing
- No default adapter for SvelteKit — server handler defaults to `deepagentsAdapter` (strips messageId), but SvelteKit handler is a clean proxy; consumers who need normalization pass the adapter explicitly
- Standard `new Response()` — SvelteKit uses Web standard responses, not `NextResponse`; all three response paths (502 error, no-body passthrough, stream) use `new Response`
