  <behavior>
Returns a `Readable<DeepAgentsState>` store that lazily starts the SSE fetch on first subscriber (via `StartStopNotifier` — the `start` parameter of `writable`). Stops (aborts) the fetch when the last subscriber detaches.

Store interface:
```typescript
export function createDeepAgentsStore(
  endpoint: string,
  options?: { sessionId?: string; body?: Record<string, unknown> }
): Readable<DeepAgentsState>
```

`DeepAgentsState` (defined in types.ts):
```typescript
{
  messages: unknown[];   // accumulates parsed SSE frame data objects
  status: 'idle' | 'loading' | 'streaming' | 'done' | 'error';
  error: Error | null;
}
```

Status machine (inline conditionals, not FSM library — 5-state machine is simple enough):
- Initial: `{ messages: [], status: 'idle', error: null }`
- On fetch start: `status = 'loading'`
- On first SSE data frame received: `status = 'streaming'`
- On stream close (reader done): `status = 'done'`
- On fetch/stream error: `status = 'error'`, `error = caught Error`

SSE parse loop inside the StartStopNotifier `start` function:
1. Create `AbortController`
2. Call `fetch(endpoint, { method: 'POST', signal: controller.signal, ... })`
3. Set status → `loading`
4. Read body via `response.body.getReader()` in a while loop
5. Decode with `TextDecoder` and push through `SseFrameAccumulator`
6. For each complete frame: if it starts with `data: `, parse the JSON payload and push to `messages`, set status → `streaming`
7. On reader done: set status → `done`
8. On error: set status → `error`, set `error` field
9. `start` returns `() => controller.abort()` — runs when last subscriber detaches

SSR safety: Because the `start` function only runs when a subscriber attaches, the fetch never fires during SSR (no component subscribes during SSR in SvelteKit's default hydration model). Document this in JSDoc on the export.

Mock strategy for tests (no `jsdom` needed — all Node-compatible):
```typescript
global.fetch = vi.fn(() => Promise.resolve({
  status: 200,
  headers: new Headers({ 'content-type': 'text/event-stream' }),
  body: new ReadableStream({
    start(c) {

      c.close();

  }),
} as unknown as Response));
```
