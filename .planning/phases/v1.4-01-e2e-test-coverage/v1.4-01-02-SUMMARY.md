## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] PlanSchema has subtasks[] not steps[]**
- **Found during:** Task 2 implementation
- **Issue:** The plan described `PlanSchema` as `{ id, title, steps: string[] }` but the actual schema in `packages/react/src/schemas.ts` has `{ id, seq, title, markdown, subtasks: PlanSubtask[], updatedAt }`. Using `steps` would cause schema validation to fail and PlanCard to break.
- **Fix:** Adapted mock SSE payload to use full valid PlanSchema (with `seq`, `markdown`, `subtasks`, `updatedAt`); PlanCard renders `subtask.label` instead of `step`; test asserts 'step1' which matches `subtask.label` value
- **Files modified:** e2e/nextjs-extra.spec.ts, apps/example/app/page.tsx
- **Commit:** 4056650

**2. [Rule 1 - Bug] E2E-10 chunk string is 45 chars not 46**
- **Found during:** Task 2 verification (test run)
- **Issue:** "The quick brown fox jumps over the lazy dog. " is 45 characters. 22 × 45 = 990 < 1000, causing assertion failure.
- **Fix:** Raised CHUNKS from 22 to 23. 23 × 45 = 1035 >= 1000.
- **Files modified:** e2e/nextjs-extra.spec.ts
- **Commit:** 4056650

**3. [Rule 1 - Bug] TypeScript errors in page.tsx**
- **Found during:** Task 2 typecheck
- **Issue:** Initial draft imported `z` from `zod` (not a direct dependency of the app), had implicit `any` for subtask iterator, and referenced non-existent `msg.id` on a data-plan message (custom data parts have no `id` field at top level)
- **Fix:** Used `DataPlan` and `PlanSubtask` types directly from `@deepagents-nextjs/react`; used `key={subtask.id}`; keyed plan messages by index `plan-${idx}`
- **Files modified:** apps/example/app/page.tsx
- **Commit:** 4056650
