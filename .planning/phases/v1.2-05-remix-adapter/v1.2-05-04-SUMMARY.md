## Decisions Made

1. **Removed unused `@ts-expect-error` on `duplex: 'half'`** — TypeScript's fetch types now include `duplex` as a valid property. The directive was triggering a `TS2578: Unused '@ts-expect-error' directive` error during DTS build. Removed the directive; the property still works correctly.

2. **CI guard checks `@deepagents-nextjs/(react|server)` only** — The sveltekit CI guard checks for `react|next` patterns broadly. For remix this would be wrong: the hook legitimately imports `useState`/`useEffect` from `react`. The remix guard uses precise patterns `require\("@deepagents-nextjs/(react|server)` and `from "@deepagents-nextjs/(react|server)` that only catch actual cross-package leakage, not legitimate react usage.

3. **dist/ not tracked in git** — Root `.gitignore` excludes `dist/`. CI builds packages fresh via the `pnpm build` step before the dist-guard checks run. The plan's `files_modified` dist entries describe generated artifacts, not committed files.
