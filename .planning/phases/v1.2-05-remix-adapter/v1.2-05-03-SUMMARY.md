# Phase v1.2-05 Plan 03: useDeepAgentsChat React Hook Summary

**One-liner:** useDeepAgentsChat React hook with useState/fetch/ReadableStream SSE loop for Remix, identical surface to Next.js hook.

## What Was Built

`useDeepAgentsChat` React hook for the `@deepagents-nextjs/remix` package. The hook exposes `messages`, `status`, `error`, and `start()` — the same API surface as the Next.js hook. Critical design choice: uses native `fetch()` + `ReadableStream` reader loop (adapted from the SvelteKit store), NOT `useFetcher.data`, because `useFetcher` buffers the entire response before delivering it, making SSE streaming impossible.
