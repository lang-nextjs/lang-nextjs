  <behavior>
Factory signature:
`export function createDeepAgentsHandler(options: RemixHandlerOptions): (args: ActionFunctionArgs) => Promise&lt;Response&gt;`

The returned handler function:
1. Calls `assertNodeRuntime()` — throws `"@deepagents-nextjs/remix requires Node.js runtime. Cloudflare Workers and other edge runtimes are not supported in v1.2. Use @remix-run/node for your Remix deployment."` when process.versions.node is absent
2. Reads `args.request.arrayBuffer()` for the body
3. Builds forwarded headers (non-hop-by-hop):
   - HOP_BY_HOP = Set(['host', 'content-length', 'transfer-encoding', 'connection'])
   - If `getToken` provided: forward all non-hop-by-hop headers EXCEPT authorization; then call getToken(args); if returns truthy string → set `Authorization: Bearer {token}`; null/undefined/empty string → no Authorization header; throw → propagate
   - If `getToken` absent: forward ALL non-hop-by-hop headers (including any client Authorization)
4. Fetches `options.backendUrl` with method POST, forwarded headers, body, `duplex: 'half'`
5. On network error → console.error + return `new Response('upstream error', { status: 502 })`
6. If `backendResponse.body` is null → return `new Response(null, { status: backendResponse.status })`
7. Build response headers: `Content-Type: text/event-stream`, `Cache-Control: no-cache, no-transform`, `X-Accel-Buffering: no`
8. If backend response has `x-vercel-ai-ui-message-stream` header → forward it
9. Create `ReadableStream` that reads backend body, pushes through `SseFrameAccumulator`, applies `allTransforms` pipeline (adapter.transforms + options.transforms), enqueues non-null frames as `${frame.raw}\n\n`
10. Return `new Response(transformedStream, { status: backendResponse.status, headers: responseHeaders })`

allTransforms = [...(options.adapter?.transforms ?? []), ...(options.transforms ?? [])]
assertNodeRuntime placed INSIDE handler body (not module top-level — safe import in any env)

Test helper `makeArgs(opts)` — builds a minimal ActionFunctionArgs-like object:
```typescript
function makeArgs(opts: { headers?: Record<string, string>; body?: string } = {}) {
  const headers = new Headers(opts.headers ?? {});
  return {
    request: {
      headers,
      arrayBuffer: async () => new TextEncoder().encode(opts.body ?? '').buffer,
    },
  } as any;
}
```
(Identical shape to sveltekit's makeEvent — args.request is the same as event.request)
