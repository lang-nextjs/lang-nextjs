Output: timing.ts + observability.ts in server, handler.ts integration, exports, and copied type files in three framework packages.

<task type="auto">
  <name>Task 2: Integrate hooks into handler with try-catch containment</name>
  <files>packages/server/src/handler.ts, packages/server/src/handler.observability.test.ts, packages/server/src/index.ts</files>
  <action>
Extend `DeepAgentsHandlerOptions` with `observability?: ObservabilityHooks` (import from ./observability). Import `getSafeCurrentTime` from ./timing.

Add a tiny private helper `fireHook(name, fn)` inside the handler module that does `try { await fn() } catch (e) { console.error("[deepagents/server] " + name + " hook failed:", e) }` so EVERY hook invocation is wrapped uniformly (OBS-02). Hooks default to `options.observability ?? {}`.

Wire firing at these lifecycle points (use getSafeCurrentTime for timestamps, Date.now base for durationMs deltas is acceptable but prefer getSafeCurrentTime consistently):
  - `onRequest` after sessionId is established (add `const sessionId = crypto.randomUUID()` near top), before fetch — pass {sessionId, backendUrl, timestamp}.
  - `onFetchStart` immediately before `fetchWithRetry` — pass {backendUrl, timeoutMs (undefined for now), timestamp}.
  - `onFetchEnd` after fetch resolves — pass {backendUrl, status, bytesReceived: 0 (running count not yet available here — use 0 or the eventual byteCount; document), durationMs, timestamp}. Also fire on the catch path with `error` set BEFORE returning 502.
  - `onStreamStart` after confirming backendResponse.body, before building the ReadableStream — pass {backendUrl, status, timestamp}.
  - Track `frameCount` and `byteCount` accumulators in the ReadableStream start(): increment byteCount by `out.raw.length` (or encoded byte length) and frameCount per enqueued frame.
  - `onStreamEnd` in the `finally` block of the stream loop — pass {success: sawTerminalFrame, frameCount, byteCount, durationMs, error?, timestamp}.
  - `onError` on the mid-stream catch path — pass {type:"stream", error, durationMs, sessionId, timestamp}; and on the fetch-failure catch path {type:"fetch", error, ...}.
CRITICAL: no hook call may be outside fireHook(); a throwing/rejecting hook must never propagate. Do not pass `request`, `forwardedHeaders`, `body`, or any token to any hook.

Add exports to `packages/server/src/index.ts`: `export type { ObservabilityHooks } from "./observability";` and `export { getSafeCurrentTime } from "./timing";`.

Write `packages/server/src/handler.observability.test.ts` (integration, mirror existing handler.test.ts mocking style):
  - hooks fire: a sink object records calls; assert onRequest fired with a sessionId string, onStreamEnd fired with numeric frameCount>0 and byteCount>0 (OBS-01).
  - CALLBACK SAFETY (OBS-02): register hooks that throw on EVERY invocation; pipe a multi-frame mock backend; assert the response stream still yields all expected frames and closes cleanly (no truncation, no thrown error escapes). This is the CRITICAL gate from RESEARCH Pitfall 3.
  - assert no hook received a field named headers/token/body (inspect recorded call args keys) (OBS-03 runtime check).
  </action>
