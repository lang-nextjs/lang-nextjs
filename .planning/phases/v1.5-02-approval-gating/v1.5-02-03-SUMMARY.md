## What Was Built

### Task 1: createApprovalRoutes factory (approval-routes.ts)

`createApprovalRoutes()` returns two Next.js App Router handlers:

- **GET** `/api/approval/[approvalId]` — queries approval status, returns `{ id, toolCallId, toolName, status, createdAt, expiresAt }` as JSON; 404 if not found
- **POST** `/api/approval/[approvalId]` — accepts `{ decision: "approve" | "reject" }`, validates it, calls `resolveApproval()`, returns `{ id, decision, accepted: true }`; 400 on invalid decision/JSON; 404 on unknown/expired; 409 on already-resolved

[QUORUM-1] `cleanupApproval()` is NOT called in the POST handler. The approvalGating SSE transform reads `getApproval(approvalId)` on its next frame call and handles cleanup after drain. Calling cleanup here would cause `getApproval()` to return `undefined`, silently losing buffered frames.

Uses Next.js 15 async params pattern: `const { approvalId } = await context.params`.
