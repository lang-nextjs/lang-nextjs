# Phase v1.3-01 Plan 03: Example Adapter Swap UI and Consumer Test Summary

**One-liner:** Adapter swap UI (deepagents/langgraph/langchain) + canonical `createMockDeepAgentsServer` vitest consumer test in `apps/example`.

## What Was Built

### Task 1: Extend apps/example with adapter swap UI and debug/auth labels

Extended `apps/example` to demonstrate the full v1.2 feature set:

**apps/example/app/page.tsx:**
- Added `AdapterName` type union (`'deepagents' | 'langgraph' | 'langchain'`)
- Added `adapterName` state with selector UI — state-driven, no page reload on switch
- Passes `body: { adapterName }` to `useDeepAgentsChat` so the route receives the selection
- Added amber feature info strip: getCookieToken, DEBUG=deepagents:sse, useDeepAgentsChat<TData>

**apps/example/app/api/chat/stream/route.ts:**
- Imports all three adapters from `@deepagents-nextjs/server`
- Module-level `adapterMap` maps string keys to adapter objects
- Parses request body to extract `adapterName`, falls back to `deepagentsAdapter`
- Reconstructs `NextRequest` with re-serialized body before passing to handler
- Preserves 503 guard when `BACKEND_URL` is unset

**packages/react/src/hook.ts:**
- Added optional `body?: Record<string, unknown>` field to `UseDeepAgentsChatOptions`
- Body is spread into `DefaultChatTransport` body function after `sessionId`

### Task 2: Add vitest config and consumer test file to apps/example

**apps/example/vitest.config.ts:**
- Per-app vitest config using jsdom environment
- No root workspace config per v1.0-01 decision

**apps/example/example.test.ts:**
- Two test cases: SSE stream accumulation and fetch rejection error status
- Uses `createMockDeepAgentsServer({ chunkDelayMs: 0 })` — fast tests
- Canonical reference pattern for `docs/TESTING.md`

**apps/example/package.json:**
- Test script changed from `pnpm typecheck` to `vitest run`
- Added `@deepagents-nextjs/test-utils`, `vitest`, `jsdom`, `@testing-library/react` dev deps
