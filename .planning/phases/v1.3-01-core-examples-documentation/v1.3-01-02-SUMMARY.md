## Decisions Made
- tsconfig `paths` redirects `react` and `react-dom` to `./node_modules/@types/react` and `./node_modules/@types/react-dom` — prevents @types/react@19 from leaking into the remix-example typecheck via pnpm virtual store traversal
- `noEmit: true` added explicitly to tsconfig to prevent TypeScript from emitting JS/DTS files into app/routes/ which would cause Route ID collisions in the Remix Vite build
- ReactPortal augmentation via separate `react-declarations.d.ts` rather than inline in root.tsx — keeps the patch isolated and discoverable

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Fixed esbuild@0.21.5 binary version mismatch**
- **Found during:** Task 1 verification (`pnpm install`)
- **Issue:** pnpm virtual store installed esbuild@0.21.5 package but linked it to the @esbuild/darwin-arm64@0.17.6 binary, causing `Host version "0.21.5" does not match binary version "0.17.6"` error
- **Fix:** Used `pnpm install --no-frozen-lockfile --ignore-scripts` to install deps; manually copied correct binary from @esbuild+darwin-arm64@0.21.5 store path to esbuild@0.21.5 bin location
- **Files modified:** node_modules/.pnpm/esbuild@0.21.5/node_modules/esbuild/bin/esbuild (binary replacement)
- **Verification:** `esbuild --version` returns 0.21.5; `remix vite:build` succeeds
- **Committed in:** adfed97 (Task 1 commit — pnpm-lock.yaml)

**2. [Rule 1 - Bug] Fixed @types/react@18 vs @types/react@19 type collision causing typecheck failure**
- **Found during:** Task 2 verification (`pnpm --filter remix-example typecheck`)
- **Issue:** TypeScript was loading both @types/react@18.3.28 (local) and @types/react@19.2.14 (from pnpm virtual store) simultaneously. react-router@6 component types (Outlet) returned ReactElement<unknown> which wasn't assignable to ReactNode due to cross-version type incompatibility
- **Fix 1:** Added react-declarations.d.ts to augment ReactPortal.children as optional (fixes the @types/react@18.3 ReactPortal incompatibility with react-router@6)
- **Fix 2:** Added `paths` and `typeRoots` to tsconfig.json to pin @types/react resolution to local node_modules only, blocking @types/react@19 from leaking in via pnpm virtual store traversal
- **Fix 3:** Added `noEmit: true` explicitly to prevent tsconfig paths from causing TypeScript to emit .js/.d.ts files into app/routes/ which caused Remix Route ID collisions
- **Files modified:** apps/remix-example/tsconfig.json, apps/remix-example/app/react-declarations.d.ts
- **Verification:** `pnpm --filter remix-example typecheck` exits 0; `pnpm --filter remix-example build` exits 0
- **Committed in:** 8c5e928 (Task 2 commit)
