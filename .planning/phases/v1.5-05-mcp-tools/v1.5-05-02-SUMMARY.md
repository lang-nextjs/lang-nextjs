## Task 1: Add trigger_task and list_runs MCP tools (MCP-01, MCP-02)

**Status:** COMPLETE

Updated test assertion to expect 9 tools instead of 5. Added two new MCP tool registrations to createDeepAgentsMcpServer in packages/mcp/src/index.ts:

**trigger_task tool (MCP-01):**
- POST to /api/open-swe/runs with task description
- Returns run_id immediately without waiting for completion
- Validates task is not empty or whitespace; returns isError:true if invalid
- Returns isError:true on AbortError (timeout)
- Throws on 502 errors (propagates to agent)

**list_runs tool (MCP-02):**
- GET from /api/open-swe/runs
- Returns structured array of run objects with run_id, status, created_at, task fields
- Throws on 502 errors
- Returns isError:true on AbortError (timeout)

## Task 2: Add get_run_status, cancel_run tools and API routes (MCP-03, MCP-04)

**Status:** COMPLETE

**Step 1 — Added getRun and cancelRun to langgraph-client.ts:**
- getRun(runId, platformUrl): GET /runs/{runId}, returns single run object
- cancelRun(runId, platformUrl): POST /runs/{runId}/cancel, returns updated run with cancelled/failed status
- Both follow existing platformFetch pattern with makeHeaders and PlatformError handling
- Encode runId using encodeURIComponent to prevent path injection

**Step 2 — Created GET /api/open-swe/runs/[runId] route:**
- File: apps/open-swe/app/api/open-swe/runs/[runId]/route.ts
- Accepts runId as dynamic route parameter (Promise<{runId: string}>)
- Returns 502 if LANGGRAPH_PLATFORM_URL not configured
- Calls getRun(runId, platformUrl)
- Returns 502 on PlatformError with status >= 500 or AbortError (timeout)
- Returns 500 on other errors with console logging

**Step 3 — Created POST /api/open-swe/runs/[runId]/cancel route:**
- File: apps/open-swe/app/api/open-swe/runs/[runId]/cancel/route.ts
- Accepts runId as dynamic route parameter
- Returns 502 if LANGGRAPH_PLATFORM_URL not configured
- Calls cancelRun(runId, platformUrl)
- Returns 502 on PlatformError with status >= 500 or AbortError (timeout)
- Returns 500 on other errors with console logging

**Step 4 — Added get_run_status and cancel_run MCP tools:**

**get_run_status tool (MCP-03):**
- GET /api/open-swe/runs/{runId}
- Encodes runId to prevent path injection
- Validates runId is not empty or whitespace; returns isError:true if invalid
- Returns error message exactly: "runId is required and cannot be empty or whitespace"
- Returns isError:true on AbortError (timeout) with message "timeout"
- Throws on 502 errors

**cancel_run tool (MCP-04):**
- POST /api/open-swe/runs/{runId}/cancel
- Encodes runId to prevent path injection
- Validates runId is not empty or whitespace; returns isError:true if invalid
- Returns error message exactly: "runId is required and cannot be empty or whitespace"
- Does NOT wait for run to reach terminal status — returns immediate POST response
- Returns isError:true on AbortError (timeout) with message "timeout"
- Throws on 502 errors
