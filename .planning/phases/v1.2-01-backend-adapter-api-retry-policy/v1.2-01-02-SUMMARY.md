# Phase v1.2-01 Plan 02: Backend Adapter API + Retry Policy Summary

**One-liner:** SseAdapter interface + deepagentsAdapter bundle with exponential backoff fetchWithRetry, backward-compatible adapter pipeline replacing defaultTransforms.

## What Was Built

### Task 1: adapters/deepagents.ts + adapters/index.ts (commit 9931cad)

Created the `adapters/` subdirectory with:
- `SseAdapter` interface: `{ name: string; transforms: SseTransform[] }`
- `deepagentsAdapter` const: wraps `stripMessageIdTransform` under the name `'deepagents'`
- `adapters/index.ts`: re-exports both for downstream plans (v1.2-01-03/04 will add more)
- `deepagents.test.ts`: 7 unit tests covering name guard, transform count, messageId strip, pass-through cases (finish without messageId, text-delta, `[DONE]`, invalid JSON)
- `stripMessageIdTransform` exported from `transforms.ts` (was private before)

### Task 2: handler.ts adapter + retry options (commit dbcfebf)

Extended `DeepAgentsHandlerOptions` with:
- `adapter?: SseAdapter` — defaults to `deepagentsAdapter`; pipeline is `[...effectiveAdapter.transforms, ...options.transforms]`
- `retry?: { maxRetries?: number; initialDelayMs?: number }` — defaults 0/100ms

Added `fetchWithRetry` (internal, not exported):
- Exponential backoff: `delayMs = initialDelayMs * 2^attempt` after each failed attempt
- Only wraps the initial `fetch()` call — mid-stream reader errors are explicitly outside the retry scope
- On exhaustion throws; handler catch block returns 502

Added 6 retry tests to `handler.test.ts`:
1. No retry when option omitted (1 fetch call, 502)
2. Retries up to maxRetries (4 calls for maxRetries=3)
3. Exponential backoff timing (verified via fake timers)
4. Succeeds on retry (3 calls, 200 status)
5. 502 when all retries exhausted (3 calls for maxRetries=2)
6. Mid-stream does not retry (1 fetch call regardless of stream error)

### Task 3: @deprecated alias + public exports (commit 64bfb00)

- `defaultTransforms` gains `@deprecated` JSDoc pointing users to `deepagentsAdapter` — no runtime change, no console warning
- `index.ts` exports `deepagentsAdapter` and `SseAdapter` type — both now importable from `@deepagents-nextjs/server`
- All prior exports (`createDeepAgentsHandler`, `defaultTransforms`, `SseFrame`, `SseTransform`, `DeepAgentsHandlerOptions`) preserved unchanged
