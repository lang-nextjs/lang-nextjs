## What Was Built

`langGraphAdapter` is a named `SseAdapter` bundle that transforms raw LangGraph `astream_events v2` SSE frames to AI SDK v6 wire format.

### Transform behavior

| Input event (event.event field) | Output |
|----------------------------------|--------|
| `on_chat_model_stream` (non-empty content) | `{ type: 'text-delta', delta: content }` |
| `on_chat_model_stream` (empty content) | `null` (dropped) |
| `on_chain_start` | `null` (dropped) |
| `on_chain_end` | `null` (dropped) |
| `on_chain_stream` | `null` (dropped) |
| `on_chat_model_start` | `null` (dropped) |
| `on_chat_model_end` | `null` (dropped) |
| `data: [DONE]` | pass-through unchanged |
| non-JSON data | pass-through unchanged (never throws) |
| no `data: ` prefix | pass-through unchanged |
| JSON with no `event` field | pass-through unchanged |

### Fixture validation

Live fixture (`langgraph-astream-events-v2.json`, 21 frames) contains exactly 6 distinct event types. Tests use fixture frames directly — no synthetic data. Event types NOT in fixture (`on_tool_start`, `on_tool_end`, `on_llm_stream`) have no tests and no switch cases, per plan instructions.
