## What Was Built

`langchainAdapter` normalizes LangChain native SSE frames (the `event: token` / `event: message` / `event: tool_call` wire format) to AI SDK v6 frame shapes.

### Frame Mapping

| LangChain event | AI SDK v6 output | Notes |
|-----------------|-----------------|-------|
| `event: token` | `{ type: 'text-delta', delta: text }` | `text` field from fixture |
| `event: message` | `{ type: 'finish', finishReason: 'stop' }` | content intentionally dropped |
| `event: tool_call` | `{ type: 'tool-input-available', toolCallId, toolName, input }` | deterministic ID |
| `event: error` | `null` (dropped) | propagates via stream error |
| `data: [DONE]` | pass through | sentinel preserved |
| non-JSON / unknown | pass through | fail-open |

### Deterministic toolCallId

`createLangchainTransform()` closes over a `toolCallCount` variable. Each processed `tool_call` frame increments the counter. Generated IDs: `lc-{toolName}-0`, `lc-{toolName}-1`, etc. Frame-supplied `tool_call_id` takes precedence if present.
