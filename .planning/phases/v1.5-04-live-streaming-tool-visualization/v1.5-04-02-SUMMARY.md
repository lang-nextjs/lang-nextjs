## Decisions Made

| Decision | Rationale |
|----------|-----------|
| `esbuild.jsx: "automatic"` in vitest config | tsx test files fail with "React is not defined" without it; Next.js tsconfig uses `jsx: preserve` which Vitest doesn't process |
| `../../../` import paths from `app/runs/[runId]/` | Plan listed `../../` which resolves to `app/lib/` (wrong); correct path is 3 levels up to reach `apps/open-swe/lib/` |
| Route tests implemented as auto-fix | 5 route stub tests from Plan 01 were blocking success criteria (`pnpm test exits 0`); route was already implemented |
| No module-level EventSource storage | Each hook instance owns its EventSource ref; no cleanup complexity and no cross-tab leakage |
