<objective>
Create a GitHub Actions workflow that automatically deploys open-swe to a Vercel preview URL and runs smoke tests against it before allowing merge to main.
</objective>

<context>
@.github/workflows/smoke-test.yml
@apps/open-swe/deploy/canary-check.sh
@.planning/phases/17-00-canary-blue-green/17-00-RESEARCH.md

The existing `smoke-test.yml` is manual (workflow_dispatch) and checks localhost endpoints. This plan creates a new automated workflow that:
1. Triggers on every PR targeting main
2. Deploys open-swe to a Vercel preview URL using the Vercel CLI
3. Runs smoke tests against that preview URL
4. Fails the PR check if smoke tests fail (blocks merge)
</context>

<tasks>

<task type="auto">
  <name>Create automated smoke-test-staging workflow</name>
  <files>.github/workflows/smoke-test-staging.yml</files>
  <action>
    Create `.github/workflows/smoke-test-staging.yml` with the following structure:

    ```yaml
    name: Smoke Test — Staging

    on:
      pull_request:
        branches: [main]

    env:
      VERCEL_TOKEN: ${{ secrets.VERCEL_TOKEN }}
      VERCEL_ORG_ID: ${{ secrets.VERCEL_ORG_ID }}
      VERCEL_PROJECT_ID: ${{ secrets.VERCEL_PROJECT_ID }}

    jobs:
      deploy-staging:
        name: Deploy to Vercel Preview
        runs-on: ubuntu-latest
        steps:
          - name: Checkout
            uses: actions/checkout@v6

          - name: Deploy to Vercel (preview)
            working-directory: apps/open-swe
            run: |
              npx vercel deploy \
                --token=$VERCEL_TOKEN \
                --org=$VERCEL_ORG_ID \
                --project=$VERCEL_PROJECT_ID \
                --yes \
                --environment=preview
              echo "VERCEL_PREVIEW_URL=$(cat .vercel/README.json | jq -r '.url')" >> $GITHUB_ENV

          - id: get-url
            name: Extract preview URL
            run: |
              PREVIEW_URL=$(cat .vercel/README.json | jq -r '.url')
              echo "Preview URL: $PREVIEW_URL"
              echo "VERCEL_PREVIEW_URL=$PREVIEW_URL" >> $GITHUB_ENV

          - name: Show deployment URL
            run: echo "Deployed to ${{ env.VERCEL_PREVIEW_URL }}"

      smoke-test-staging:
        name: Smoke Test — Vercel Preview
        runs-on: ubuntu-latest
        needs: [deploy-staging]
        env:
          OPENSWE_HEALTH_URL: ${{ env.VERCEL_PREVIEW_URL }}/health
        steps:
          - name: Run smoke checks
            run: |
              echo "=== open-swe Health Check ==="
              STATUS=$(curl -s -o /dev/null -w "%{http_code}" "$OPENSWE_HEALTH_URL")
              if [ "$STATUS" -ne 200 ]; then
                echo "FAIL: /health returned $STATUS (expected 200)"
                exit 1
              fi
              echo "PASS: /health returned 200"

              echo "=== open-swe JSON Response Check ==="
              RESPONSE=$(curl -s "$OPENSWE_HEALTH_URL")
              if ! echo "$RESPONSE" | python3 -c "import sys, json; json.load(sys.stdin)" 2>/dev/null; then
                echo "FAIL: /health did not return valid JSON"
                exit 1
              fi
              echo "PASS: /health returned valid JSON"

              echo "=== open-swe API Runs Check ==="
              API_STATUS=$(curl -s -o /dev/null -w "%{http_code}" "$OPENSWE_HEALTH_URL/api/open-swe/runs")
              if [ "$API_STATUS" -ge 500 ]; then
                echo "FAIL: API runs route returned $API_STATUS (5xx)"
                exit 1
              fi
              echo "PASS: API runs route returned $API_STATUS"

              echo "=== All smoke checks passed ==="

      smoke-test-result:
        name: Smoke Test — Result
        runs-on: ubuntu-latest
        needs: [smoke-test-staging]
        if: always()
        steps:
          - name: Set result summary
            run: |
              echo "## Smoke Test Results" >> $GITHUB_STEP_SUMMARY
              echo "" >> $GITHUB_STEP_SUMMARY
              echo "| Check | Status |" >> $GITHUB_STEP_SUMMARY
              echo "| --- | --- |" >> $GITHUB_STEP_SUMMARY
              echo "| Deploy to Vercel Preview | ${{ needs.deploy-staging.result }} |" >> $GITHUB_STEP_SUMMARY
              echo "| Smoke Tests | ${{ needs.smoke-test-staging.result }} |" >> $GITHUB_STEP_SUMMARY
              if needs.smoke-test-staging.result == 'failure'; then
                echo ""
                echo "Smoke tests failed. PR is blocked from merging."
                exit 1
              fi
    ```

    Key design decisions:
    - Trigger: `pull_request` targeting `main` — automated on every PR
    - Environment: `--environment=preview` ensures preview URL, not production
    - Health check: Uses `/health` endpoint (from plan 17-01) — proper liveness probe
    - Blocking: `exit 1` on any failed check — fails the PR check, blocks merge
    - Secrets required: `VERCEL_TOKEN`, `VERCEL_ORG_ID`, `VERCEL_PROJECT_ID`
    - Vars required: None (preview URL extracted from .vercel/README.json)
  </action>
