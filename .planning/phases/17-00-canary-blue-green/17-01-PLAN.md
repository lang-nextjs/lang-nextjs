<objective>
Add a stateless `/health` endpoint to the open-swe Next.js app so smoke tests and load balancers have a proper liveness probe instead of checking the root page.
</objective>

<context>
@.planning/phases/17-00-canary-blue-green/17-00-RESEARCH.md
@apps/fastapi-backend/main.py
@apps/django-backend/ (health endpoint pattern)
@apps/open-swe/deploy/canary-check.sh

The FastAPI backend has `GET /health` returning `{"status":"ok","ai_backends":[...]}`. Django has `GET /health/` with the same shape. The open-swe app has no `/health` endpoint — the canary-check.sh currently checks the root page (`/`) as a proxy, which can pass even when API routes are broken. A proper stateless liveness probe is needed.
</context>
