### Key Design Decisions Verified

1. **Debug namespace matching is exact** — `shouldDebug()` splits on commas and checks for exact match of `'deepagents:sse'`. Wildcard `*` is excluded to keep overhead minimal when unset. Confirmed in 5 unit tests.

2. **Cookie reading uses synchronous API** — `getCookieToken()` uses `NextRequest.cookies.get()` (synchronous Web API available in Route Handlers), NOT the async `cookies()` from `next/headers` (which only works in Server Components). Decision documented in code comment and enforced by type signature.

3. **SSE frame parse errors don't corrupt stream** — `logSseFrame()` wraps all parsing in try-catch and silently skips errors. Non-JSON data lines (e.g., `[DONE]` tokens, event headers) are handled gracefully. Verified in 4 error-case tests.

4. **Mock server uses AI SDK v6 native format** — `createMockDeepAgentsServer()` uses `streamText().toUIMessageStreamResponse()` directly, emitting the exact same `UIMessageStream` format that `useDeepAgentsChat()` consumes. Verified in 7 integration tests against actual Response properties.

5. **Fail-open auth behavior** — `getCookieToken()` returns `undefined` when cookie is absent (no exception). Handler then sends no Authorization header. This fail-open behavior is correct per CONTEXT.md locked decision. Verified in 2 unit tests.
