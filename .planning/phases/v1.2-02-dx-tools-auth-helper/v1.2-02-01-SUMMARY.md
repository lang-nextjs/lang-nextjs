## What Was Built

### DX-01: debug.ts + handler.ts integration

`shouldDebug()` reads `process.env.DEBUG`, splits on commas, and checks for exact match of `'deepagents:sse'`. Wildcards (`*`) are intentionally excluded — exact match only keeps overhead minimal.

`logSseFrame()` finds the `data: ` line in a raw SSE frame, skips `[DONE]` tokens, parses JSON, and emits `console.error('[deepagents:sse] frame: {...}')`. All parse errors are swallowed silently — frame corruption is not acceptable.

Both calls wired into `handler.ts` streaming loop — flush path (done branch) and normal push path — as:
```typescript
if (shouldDebug()) logSseFrame(transformed)
```
Zero overhead when `DEBUG` is unset: `shouldDebug()` checks a single env var and returns immediately.

### AUTH-01: get-cookie-token.ts

`getCookieToken(cookieName)` returns a `(req: NextRequest) => string | undefined` function compatible with the handler's `getToken` option. Uses `req.cookies.get(cookieName)?.value` — the synchronous Web API on `NextRequest`. The async `cookies()` from `next/headers` was explicitly avoided as it only works in Server Components.

Fail-open behavior matches existing handler contract:
- Cookie present → returns value → handler injects `Authorization: Bearer {value}`
- Cookie absent → returns `undefined` → handler sends no Authorization header
