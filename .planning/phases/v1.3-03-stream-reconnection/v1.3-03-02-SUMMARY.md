## Key Decisions

- `createResumableStreamContext` not available in ai@6.x at this version; direct ReadableStream
  pipe used as fallback. Comment documents the limitation and expected upgrade path.
- `markStreamDone` called in `finally` block (not just success path) — ensures reconnect
  responds 204 after stream ends, preventing stale reconnect attempts.
- `x-resume-id` header guard: only emitted when `enableReconnect && resumeId` both truthy —
  prevents leaking header when reconnect is disabled.
- `vi.mock('./stream-registry')` placed at file scope (not inside describe) — required for
  vitest hoisting to work correctly before module imports.
