<feature name="stream-registry">
  <files>
    packages/server/src/stream-registry.ts
    packages/server/src/stream-registry.test.ts
  </files>
  <behavior>
    In-memory Map singleton keyed by resumeId (string). Survives Next.js HMR via `(globalThis as any).__deepagents_stream_registry ??= new Map()` pattern.

    registerStream(resumeId, streamId): void — stores { streamId, createdAt: Date.now(), done: false }
    lookupStream(resumeId): StreamRecord | undefined — returns undefined if not found OR if createdAt is older than TTL_MS (5 * 60 * 1000); evicts on lookup (lazy TTL)
    markStreamDone(resumeId): void — sets record.done = true; no-op if not found
    deleteStream(resumeId): void — removes entry from map

    Cases:
    registerStream('abc', 'stream-1') → lookupStream('abc') returns { streamId: 'stream-1', done: false }
    registerStream('abc', 'stream-1') → markStreamDone('abc') → lookupStream('abc') returns { done: true }
    lookupStream('nonexistent') → returns undefined
    lookupStream called with expired createdAt (>TTL_MS ago) → returns undefined + evicts entry
    registerStream('abc', '1') → registerStream('abc', '2') → lookupStream('abc') returns streamId '2' (overwrite)
    deleteStream('abc') → lookupStream('abc') returns undefined
  </behavior>
  <implementation>
    Create packages/server/src/stream-registry.ts:

    ```typescript
    interface StreamRecord {
      streamId: string;
      createdAt: number;
      done: boolean;
    }

    const TTL_MS = 5 * 60 * 1000; // 5 minutes

    // Stable singleton that survives Next.js HMR — mirrors Prisma client pattern
    function getRegistry(): Map<string, StreamRecord> {
      const g = globalThis as unknown as { __deepagents_stream_registry?: Map<string, StreamRecord> };
      g.__deepagents_stream_registry ??= new Map();
      return g.__deepagents_stream_registry;
    }

    export function registerStream(resumeId: string, streamId: string): void {
      getRegistry().set(resumeId, { streamId, createdAt: Date.now(), done: false });
    }

    export function lookupStream(resumeId: string): StreamRecord | undefined {
      const registry = getRegistry();
      const record = registry.get(resumeId);
      if (!record) return undefined;
      if (Date.now() - record.createdAt > TTL_MS) {
        registry.delete(resumeId);
        return undefined;
      }
      return record;
    }

    export function markStreamDone(resumeId: string): void {
      const record = getRegistry().get(resumeId);
      if (record) record.done = true;
    }

    export function deleteStream(resumeId: string): void {
      getRegistry().delete(resumeId);
    }
    ```

    Note: Do NOT export `StreamRecord` as a named export from index.ts — it is an internal type. Only the four functions are exported.
  </implementation>
</feature>

    isStreamReconnectEnabled(): boolean — returns process.env.ENABLE_STREAM_RECONNECT === 'true'

    createDeepAgentsResumeHandler(): NextRequest GET handler factory.
    - When flag off: returns NextResponse with status 503, body 'stream reconnection disabled (set ENABLE_STREAM_RECONNECT=true)'
    - When flag on + resumeId not in registry OR record.done=true: returns NextResponse null body status 204
    - When flag on + resumeId in registry + done=false: streams from in-memory context using stored streamId

    Cases:
    isStreamReconnectEnabled() with ENABLE_STREAM_RECONNECT=undefined → false
    isStreamReconnectEnabled() with ENABLE_STREAM_RECONNECT='false' → false
    isStreamReconnectEnabled() with ENABLE_STREAM_RECONNECT='true' → true
    GET handler, flag off → 503
    GET handler, flag on, resumeId not in registry → 204
    GET handler, flag on, record.done=true → 204

    NOTE: The full streaming resumption path (resumeExistingStream) is complex and requires
    createResumableStreamContext from 'ai'. For this TDD plan, implement the flag guard and
    the 503/204 paths. The streaming path (status 200) will be a stub that returns 204 with
    a TODO comment — it is wired up fully in Plan 02 after the integration is tested.
    The test file does NOT need to test the 200 streaming path.
  </behavior>
  <implementation>
    Create packages/server/src/reconnect.ts:

    ```typescript
    import { NextRequest, NextResponse } from 'next/server';
    import { lookupStream } from './stream-registry';

    export function isStreamReconnectEnabled(): boolean {
      return process.env.ENABLE_STREAM_RECONNECT === 'true';
    }

    export function createDeepAgentsResumeHandler() {
      return async function GET(
        _: NextRequest,
        { params }: { params: Promise<{ resumeId: string }> }
      ): Promise<NextResponse> {
        if (!isStreamReconnectEnabled()) {
          return new NextResponse(
            'stream reconnection disabled (set ENABLE_STREAM_RECONNECT=true)',
            { status: 503 }
          );
        }

        const { resumeId } = await params;
        const record = lookupStream(resumeId);

        if (!record || record.done) {
          return new NextResponse(null, { status: 204 });
        }

        // TODO(STR-01): Resume active stream via createResumableStreamContext
        // Full implementation requires wiring the stream context singleton.
        // For now return 204 — Plan 02 completes the streaming path.
        return new NextResponse(null, { status: 204 });
      };
    }
    ```
