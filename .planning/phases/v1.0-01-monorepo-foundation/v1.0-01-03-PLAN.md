<objective>
Create the `@deepagents-nextjs/react` package skeleton: package manifest with React as a peerDependency (not a dependency), tsup config externalizing React to prevent duplicate module instances, per-package TypeScript config, Vitest config, and a minimal source + smoke test.

Purpose: The react package skeleton mirrors the server skeleton in structure but has a critical difference: React MUST be a peerDependency. Bundling React as a direct dependency causes duplicate React instances in consumer apps, breaking hooks. This plan locks in the correct dependency topology before any feature code is written.

Output: A fully buildable `packages/react/` directory. `turbo build --filter @deepagents-nextjs/react` exits 0 and produces `.js`, `.cjs`, `.d.ts`, `.d.cts` files in `dist/`.

**packages/react/package.json** — publishable, dual ESM/CJS exports, React + Zod as peerDependencies (NEVER as dependencies — duplicate React instances break hooks in consumer apps).

Key devDependencies notes:
- `react` and `react-dom` must be in devDependencies (not only peerDependencies) so tsup/tsc can resolve `react/jsx-runtime` during build
- `jsdom` must be in devDependencies so it is installed at `pnpm install` time before `vitest` tries to load the jsdom environment

```json
{
  "name": "@deepagents-nextjs/react",
  "version": "0.1.0",
  "private": false,
  "description": "DeepAgents Next.js React hook",
  "main": "./dist/index.cjs",
  "module": "./dist/index.js",
  "types": "./dist/index.d.ts",
  "sideEffects": false,
  "exports": {
    ".": {
      "import": {
        "types": "./dist/index.d.ts",
        "default": "./dist/index.js"
      },
      "require": {
        "types": "./dist/index.d.cts",
        "default": "./dist/index.cjs"
      }
    }
  },
  "files": ["dist"],
  "publishConfig": {
    "access": "public"
  },
  "scripts": {
    "build": "tsup",
    "test": "vitest run",
    "typecheck": "tsc --noEmit",
    "lint": "echo 'lint placeholder'"
  },
  "peerDependencies": {
    "react": "^18.0.0 || ^19.0.0",

}

**packages/react/tsconfig.json** — extends shared base, adds `jsx` for React (skeleton only, no JSX yet but needed for future phases):

  },
  "include": ["src"]
}
```

**packages/react/tsup.config.ts** — dual ESM+CJS, externalize React and all future peer deps so they are NEVER bundled:
```typescript
import { defineConfig } from 'tsup';

export default defineConfig({
  entry: ['src/index.ts'],
  format: ['esm', 'cjs'],
  dts: true,
  sourcemap: true,
  clean: true,
  target: 'es2020',
  treeshake: true,
  external: ['react', 'react-dom', 'ai', '@ai-sdk/react', 'zod'],
});
```

The `external` array is comprehensive even though `ai`, `@ai-sdk/react`, and `zod` are not yet dependencies — this prevents accidental bundling if they are added without updating the external list.
