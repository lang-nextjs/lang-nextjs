## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Fixed tsup output extension mismatch causing publint failure**
- **Found during:** Task 2 (server source skeleton and build smoke)
- **Issue:** tsup without outExtension generates .mjs (ESM) and .cjs (CJS) by default, but the plan's exports field expected .js (ESM) and .cjs (CJS). Without `"type": "module"`, .js is treated as CJS by Node, and publint reported the ESM bundle as CJS-interpreted.
- **Fix:** Added `"type": "commonjs"` to package.json and `outExtension({ format }) { return { js: format === 'esm' ? '.mjs' : '.js' } }` to tsup.config.ts. Updated exports field to use .mjs/.d.mts for import and .js/.d.ts for require.
- **Files modified:** packages/server/package.json, packages/server/tsup.config.ts
- **Verification:** `pnpm dlx publint packages/server` exits 0 with "All good!"
- **Committed in:** `3e3173d` (Task 2 commit)
