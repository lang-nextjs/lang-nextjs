Create `packages/server/` directory and three configuration files.

**packages/server/package.json** — publishable, dual ESM/CJS exports, `sideEffects: false` for tree-shaking.

The `exports` field MUST have `"types"` first inside each condition block — this is required for TypeScript to resolve declarations. `"default"` after `"types"` in each condition block:

```json
{
  "name": "@deepagents-nextjs/server",
  "version": "0.1.0",
  "private": false,
  "description": "DeepAgents Next.js server handler",
  "main": "./dist/index.cjs",
  "module": "./dist/index.js",
  "types": "./dist/index.d.ts",
  "sideEffects": false,
  "exports": {
    ".": {
      "import": {
        "types": "./dist/index.d.ts",
        "default": "./dist/index.js"
      },
      "require": {
        "types": "./dist/index.d.cts",
        "default": "./dist/index.cjs"
      }
    }
  },
  "files": ["dist"],
  "publishConfig": {
    "access": "public"
  },
  "scripts": {
    "build": "tsup",
    "test": "vitest run",
    "typecheck": "tsc --noEmit",
    "lint": "echo 'lint placeholder'"
  },
  "devDependencies": {
    "tsup": "^8.0.0",
    "typescript": "^5.8.3",
    "vitest": "^3.2.0"
  }
}
```

Note: tsup emits `.js` (ESM) and `.cjs` (CJS) by default — no `outExtension` override needed. The exports field above matches these defaults exactly.

**packages/server/tsconfig.json** — extends shared base, scoped to `src/`:
```json
{
  "extends": "../../tsconfig.base.json",
  "compilerOptions": {
    "outDir": "./dist",
    "rootDir": "./src"
  },
  "include": ["src"]
}
```

**packages/server/tsup.config.ts** — dual ESM+CJS, dts, no bundled peer deps. There are no peer deps in this skeleton phase; the `external` array is future-proofing for Phase v1.0-02:
```typescript
import { defineConfig } from 'tsup';

export default defineConfig({
  entry: ['src/index.ts'],
  format: ['esm', 'cjs'],
  dts: true,
  sourcemap: true,
  clean: true,
  target: 'es2020',
  treeshake: true,
});
```
