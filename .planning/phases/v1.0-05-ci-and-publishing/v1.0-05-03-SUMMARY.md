## Publish Workflow Design

**Trigger:** Every push to `main`

**How it operates:**
1. When changesets exist in `.changeset/`: bot creates/updates a "Version Packages" PR (bumps package.json, writes CHANGELOG)
2. When version PR merges: no changesets remain → `changesets/action` runs `pnpm changeset publish` → both packages publish atomically (fixed versioning)

**Permissions:**
- `contents: write` — bot pushes version bump commits, creates GitHub releases + tags
- `id-token: write` — OIDC token for npm provenance attestation
- `pull-requests: write` — bot creates/updates the "Version Packages" PR

**OIDC authentication:**
- `registry-url: https://registry.npmjs.org` in setup-node configures npm registry
- `NPM_CONFIG_PROVENANCE: "true"` requests provenance attestation during publish
- No `NPM_TOKEN` secret referenced — GitHub OIDC exchange handles authentication
- `fetch-depth: 0` — full git history required for Changesets to detect changed packages
