# Wave 2 — CI Workflow (SUMMARY)

## Outcome

`.github/workflows/ci.yml` created and YAML-valid. Runs on every PR targeting `main` and every push to `main`. Cancels stale runs via `concurrency` group.

## Files Created

- `.github/workflows/ci.yml`

## CI Workflow Steps

1. `actions/checkout@v4`
2. `pnpm/action-setup@v4` — reads `packageManager: "pnpm@9.0.0"` from root package.json automatically
3. `actions/setup-node@v4` — Node.js 22 LTS, pnpm cache
4. `pnpm install --frozen-lockfile`
5. `pnpm build` — Turborepo build in dependency order (server → react → example)
6. `pnpm test` — Turborepo test (vitest run for both packages)
7. `pnpm typecheck` — tsc --noEmit across all packages
8. `pnpm turbo validate` — runs `publint && attw --pack .` for both packages

## SC-2 Evidence

- GHA workflow runs `turbo build`, `turbo test`, and validation gates on every PR
- `pnpm turbo validate` is the gate step for `publint` + `attw --pack .`
- YAML validated: `python3 -c "import yaml; yaml.safe_load(...)"` exits 0

## Branch Protection Note

After push to GitHub: configure branch protection for `main` to require the "Build, Test, Validate" job as a required status check. This is a one-time manual step in GitHub repo settings.
