# Plan v1.0-05-01: Changesets Init and Local Validation Gates

## Goal

Initialize Changesets for the monorepo and verify that `publint` and `attw` both pass locally for both packages. This wave establishes the publishing foundation that Wave 2 (CI) and Wave 3 (publish workflow) depend on.

## Context

Both packages already have:
- `publishConfig: { access: "public" }` in package.json
- `publint` in devDependencies
- `version: "0.1.0"` (non-private)

Missing:
- `@changesets/cli` in root devDependencies
- `.changeset/config.json`
- `@arethetypeswrong/cli` (`attw`) — not yet installed anywhere

## Tasks

<task id="1">
<title>Install @changesets/cli at root and initialize Changesets</title>
<action>
1. Add `@changesets/cli` to root devDependencies:
   ```bash
   pnpm add -D @changesets/cli -w
   ```

2. Initialize Changesets:
   ```bash
   pnpm changeset init
   ```
   This creates `.changeset/config.json` with default config.

3. Update `.changeset/config.json` to match project decisions:
   ```json
   {
     "$schema": "https://unpkg.com/@changesets/config@3.0.0/schema.json",
     "changelog": "@changesets/cli/changelog",
     "commit": false,
     "fixed": [["@deepagents-nextjs/server", "@deepagents-nextjs/react"]],
     "linked": [],
     "access": "public",
     "baseBranch": "main",
     "updateInternalDependencies": "patch",
     "ignore": []
   }
   ```

   Key fields:
   - `fixed`: both packages version together (they are coupled)
   - `access: "public"`: scoped packages default to private; this overrides
   - `commit: false`: changeset bot handles commits
   - `baseBranch: "main"`: standard

4. Add a `.changeset/README.md` note explaining the versioning strategy (auto-created by `changeset init`, leave as-is).
</action>
<done>
- `.changeset/config.json` exists with `fixed: [["@deepagents-nextjs/server", "@deepagents-nextjs/react"]]`
- `@changesets/cli` appears in root `package.json` devDependencies
- `pnpm install` succeeds from repo root
</done>
</task>

<task id="2">
<title>Install @arethetypeswrong/cli and verify publint + attw for both packages</title>
<action>
1. Add `@arethetypeswrong/cli` to both packages as a devDependency:
   ```bash
   pnpm add -D @arethetypeswrong/cli --filter @deepagents-nextjs/server
   pnpm add -D @arethetypeswrong/cli --filter @deepagents-nextjs/react
   ```

2. Add `validate` script to both package.json files:
   ```json
   "validate": "publint && attw --pack ."
   ```

3. Add `validate` task to root turbo.json (optional — for CI convenience):
   In `turbo.json`, add under `tasks`:
   ```json
   "validate": {
     "dependsOn": ["build"],
     "outputs": []
   }
   ```

4. Build both packages from root:
   ```bash
   pnpm build
   ```

5. Run validation for both packages:
   ```bash
   cd packages/server && pnpm validate && cd ../../packages/react && pnpm validate
   ```
   Both must exit 0.
</action>
<done>
- `pnpm validate` exits 0 in `packages/server/`
- `pnpm validate` exits 0 in `packages/react/`
- `publint` reports "All good!" for both
- `attw --pack .` reports no problems for both
</done>
</task>
