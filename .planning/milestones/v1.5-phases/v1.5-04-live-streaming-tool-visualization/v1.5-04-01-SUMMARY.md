### Task 2: SSE Proxy Route Implementation

`GET /api/open-swe/runs/[runId]/stream` implemented:
- Returns **400** when `threadId` query param is absent
- Returns **502** when `LANGGRAPH_PLATFORM_URL` env var is unset
- Returns **502** when upstream fetch fails or times out (30s connect timeout)
- Returns **200 text/event-stream** when upstream responds successfully
- Forwards `data: [DONE]` sentinel unchanged for client-side stream-end detection
- `X-Accel-Buffering: no` and `Cache-Control: no-cache, no-transform` headers set

## Decisions Made

| Decision | Rationale |
|----------|-----------|
| Stateless proxy — no server-side transform | Avoids per-request closure state; client-side normalization via useRunStream in Plan 02 |
| `threadId` as query param | Option A from research — simple, no headers needed for EventSource |
| `STREAM_TIMEOUT_MS = 30_000` connect-only | Stream body must be unbounded for long-running agent runs |
| `export const dynamic = "force-dynamic"` | Required for SSE in Next.js App Router (mirrors runs/route.ts) |
| Stubs use `never` return type + `throw` | Module imports resolve; tests fail at runtime not import time |
