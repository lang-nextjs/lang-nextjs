## What Was Built

### openSweHeartbeat.ts — 76 lines

**Exported surface:**
- `createHeartbeatStream(upstream, options?)` — ReadableStream transform factory
- `HeartbeatOptions` interface — `{ intervalMs?: number }` (default 25_000ms)

**Implementation pattern:**
```typescript
export function createHeartbeatStream(
  upstream: ReadableStream<Uint8Array>,
  options?: HeartbeatOptions
): ReadableStream<Uint8Array> {
  return new ReadableStream<Uint8Array>({
    async start(controller) {
      // All timer state lives inside this callback — no module-level state
      let heartbeatTimer: ReturnType<typeof setTimeout> | null = null;
      function scheduleHeartbeat() { ... setTimeout → enqueue(HEARTBEAT_FRAME) ... }
      scheduleHeartbeat();
      // Read loop: scheduleHeartbeat() resets timer on each upstream chunk
      // Finally: clearTimeout, releaseLock, controller.close()
    },
  });
}
```

**Key behaviors:**
- Upstream bytes pass through unchanged (no transformation of content)
- After `intervalMs` of silence, enqueues `": keep-alive\n\n"` SSE comment frame
- Timer resets on every upstream chunk — continuous streams never receive heartbeat
- Timer cleared in `finally` block — no timer leak on upstream close or cancel
- `HEARTBEAT_FRAME` is a module-level constant (immutable, not state — acceptable)

## Key Decisions Locked In

1. **All timer state inside ReadableStream start() callback:** The per-request heartbeat timer (`heartbeatTimer`) is declared inside the `start(controller)` callback, not at module level. Each `createHeartbeatStream()` call creates a completely independent timer scope. This satisfies the v1.5 roadmap design constraint.

2. **setTimeout rescheduled rather than setInterval:** After each heartbeat emission, `scheduleHeartbeat()` is called again recursively. This avoids `setInterval`'s potential drift and makes cleanup trivial — a single `clearTimeout` in the `finally` block is sufficient.

3. **HEARTBEAT_FRAME as module-level constant:** `const HEARTBEAT_FRAME = new TextEncoder().encode(": keep-alive\n\n")` is module-level but immutable — it is shared across requests as a read-only byte buffer, not mutable state. This is safe and avoids re-encoding on every heartbeat.
