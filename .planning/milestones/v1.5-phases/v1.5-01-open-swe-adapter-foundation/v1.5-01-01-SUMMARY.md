## Key Decisions Locked In

1. **Stateless Adapter Pattern**: openSweAdapter.transforms is a getter, not a plain array. Each access returns fresh createOpenSweTransform() instances. Prevents inter-request state leakage and allows each request to have independent toolCallId counters and reorder buffers.

2. **toolCallId Format**: `${run_id}--${toolName}-${counter}` (e.g., `"run-abc--bash_execute-0"`). Counter increments per (run_id, toolName) pair, resets across different tools or runs. Deterministic and human-readable.

3. **FIFO Queue Pairing**: End events are paired to their toolCallId via `queue.shift()` on a per-(run_id, toolName) FIFO queue. Each start event pushes its generated toolCallId; each end event pops the oldest. This ensures correct pairing even when ends arrive out-of-order, without reconstructing counters (which would fail if calls are interleaved).

4. **Reorder Buffer**: Maintains `startOrder` list of emitted start toolCallIds and `endBuffer` map of buffered ends. When an end arrives, if it matches the head of startOrder, emit it and flush any subsequent buffered ends. If it does NOT match, buffer it. Ensures end events are emitted in the order start events were received.

5. **Inheritance from langGraphAdapter**: on_chat_model_stream → text-delta, [DONE] pass-through, non-JSON pass-through patterns inherited from existing adapter. New capability: on_tool_start/end mapping.
