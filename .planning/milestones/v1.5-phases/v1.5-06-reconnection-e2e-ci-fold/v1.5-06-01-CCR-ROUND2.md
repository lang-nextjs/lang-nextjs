## Improvements (Non-Blocking)

1. **Documentation:** Consider adding a phase-level README explaining the wave split (Plan 01 = local dev setup, Plan 02 = CI infrastructure). This helps future reviewers understand the architectural decision.

2. **CI Env Var:** Plan 02 should explicitly set PLAYWRIGHT_OPENSWE_URL in the "Run mocked E2E tests" step environment (currently relies on default 'http://localhost:3001'). Current approach is correct but could be made more explicit:
   ```yaml
   - name: Run mocked E2E tests

       PLAYWRIGHT_OPENSWE_URL: http://localhost:3001

       CI: 'true'
     run: pnpm test:e2e
   ```
   This makes the port 3001 assumption visible in the workflow (good practice).
