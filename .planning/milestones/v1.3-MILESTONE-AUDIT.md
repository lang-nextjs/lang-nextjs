### Implementation — Known Limitations (documented)

4. **ai@6.x createResumableStreamContext unavailable**: `reconnect.ts` uses direct `ReadableStream` pipe as fallback. Documented in code comment + README. Upgrade path: resolve AI SDK bugs #6502 + #11865 in v1.4.
5. **Stream storage not captured on POST**: `handler.ts` calls `registerStream(resumeId, uuid)` without storing the `ReadableStream`. The GET 200 path can only replay streams if the `stream` field is populated via the optional third argument to `registerStream`. Full stream capture is a v1.4 target.
