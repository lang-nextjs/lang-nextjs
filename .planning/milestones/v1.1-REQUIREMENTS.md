# Requirements: deepagents-nextjs

**Defined:** 2026-04-29
**Core Value:** A Next.js developer can wire up DeepAgents end-to-end in two lines of code — one server route, one React hook — and get fully typed messages out of the box.

## v1 Requirements

### Server Package

- [ ] **SRV-01**: Consumer can install `@deepagents-nextjs/server` and create a streaming Next.js App Router POST handler in one line via `createDeepAgentsHandler({ backendUrl, getToken?, transforms? })`
- [ ] **SRV-02**: Handler proxies SSE stream from DeepAgents Django backend to AI SDK v6 client with correct `x-vercel-ai-ui-message-stream: v1` header
- [ ] **SRV-03**: Handler applies a configurable `transforms[]` pipeline to SSE frames — each transform is `(frame: SseFrame) => SseFrame | null` (null drops the frame)
- [ ] **SRV-04**: `defaultTransforms` array strips `messageId` from `finish` events out of the box
- [ ] **SRV-05**: SSE frame accumulator (`SseFrameAccumulator`) handles frames split across TCP chunks without corruption
- [ ] **SRV-06**: Handler returns typed `Response` with status 502 when backend is unreachable, 500 on mid-stream error

### React Package

- [ ] **RCT-01**: Consumer can install `@deepagents-nextjs/react` and call `useDeepAgentsChat({ sessionId, endpoint })` to get typed `messages`, `sendMessage`, `status`, `error`
- [ ] **RCT-02**: `messages` is typed as `(UserMessage | AIMessage | ToolCallMessage | ErrorMessage)[]` discriminated union
- [ ] **RCT-03**: Zod schemas exported for all custom `data-*` SSE parts: `data-plan`, `data-task`, `data-file`, `data-approval`
- [ ] **RCT-04**: React and Zod declared as `peerDependencies` (not `dependencies`) to prevent duplicate module instances

### Monorepo & Publishing

- [x] **PKG-01**: pnpm workspaces + Turborepo configured with correct build order (server → react → example)
- [x] **PKG-02**: Both packages ship dual ESM/CJS via tsup with correct `exports` field and TypeScript declaration files
- [ ] **PKG-03**: Changesets configured for versioning and npm publishing with OIDC provenance
- [ ] **PKG-04**: `publint` and `are-the-types-wrong` pass in CI before any publish

### Example App

- [ ] **EX-01**: `apps/example/` — Next.js app demonstrating end-to-end usage against a mock SSE server (no real DeepAgents instance required to run)

## v1.1 Requirements

### Reference Backend Stacks

- [x] **E2E-01**: `apps/django-backend/` — Django 5 service using `langchain-ai/deepagents` (`create_deep_agent()`) internally, emitting the DeepAgents SSE wire format via `StreamingHttpResponse`. Compose stack includes postgres + redis.
- [x] **E2E-02**: `apps/fastapi-backend/` — FastAPI service using `langchain-ai/deepagents` (`create_deep_agent()`) internally, emitting the same DeepAgents SSE wire format via `StreamingResponse`. Single-container compose (no postgres/redis).
- [x] **E2E-03**: `apps/example/` extended to use `createDeepAgentsHandler({ backendUrl: process.env.BACKEND_URL! })` when `BACKEND_URL` is set; existing mock route preserved as `route.mock.ts`.
- [x] **E2E-04**: Shared Playwright E2E test suite (`e2e/chat.spec.ts`) validates: SSE stream delivery, `finish` frame has no `messageId` (proves `defaultTransforms` ran), stream closes cleanly. Suite runs against both backends via `BACKEND_URL`.
- [x] **E2E-05**: CI jobs (`e2e-django`, `e2e-fastapi`) run the shared E2E suite against each backend independently on every PR (skipped on external PRs without secret access).

## v2 Requirements

Tracked for future milestones. Not in current roadmap.

### Stream Resilience

- **V2-STR-01**: Stream reconnection via AI SDK `experimental_resume` — blocked on upstream bugs (#6502, #9707); revisit when AI SDK resolves these
- **V2-STR-02**: Configurable retry policy on backend connection failure (exponential backoff, max retries)

### Backend Adapters

- **V2-ADAPT-01**: Named backend adapters shipped in `@deepagents-nextjs/server` (one package, not split) — `adapter` option on `createDeepAgentsHandler({ backendUrl, adapter: langGraphAdapter })`. Each adapter is a `{ name, transforms: SseTransform[] }` bundle that normalizes a backend's SSE format to AI SDK v6. Ship at minimum: `deepagentsAdapter` (current default), `langGraphAdapter`, `langchainAdapter`.

### Framework Adapters

- **V2-FWK-01**: SvelteKit adapter (`@deepagents-nextjs/sveltekit`) — server handler + hook for SvelteKit's load functions
- **V2-FWK-02**: Remix / React Router v7 adapter — handler factory compatible with Remix's loader/action pattern

### DX & Tooling

- **V2-DX-01**: Debug logging mode — emit parsed SSE frames to console in development builds
- **V2-DX-02**: `createMockDeepAgentsServer()` utility for consumer test suites (extracted from example app into a dedicated test-utils export)
- **V2-DX-03**: TypeScript generics for custom `data-*` part schemas — let consumers extend the type system without forking

### Auth Helpers

- **V2-AUTH-01**: Built-in auth helpers for cookie-based token extraction (not just header-based `getToken`)

## Out of Scope

| Feature | Reason |
|---------|--------|
| Chat UI components | Transport + types only — UI is the consumer's responsibility |
| DeepAgents backend / Django | This is the frontend glue layer only |
| Pages Router support | App Router only in v1 — Pages Router is legacy |
| CLI / init scaffolding | Handler factory covers one-line setup without it |
| WebSocket transport | SSE is the DeepAgents protocol; WebSocket adds complexity for no benefit |
