# Requirements: deepagents-nextjs

**Defined:** 2026-05-01
**Core Value:** A Next.js developer can wire up DeepAgents end-to-end in two lines of code — one server route, one React hook — and get fully typed messages out of the box.

## v1.2 Requirements

### Backend Adapters

- [x] **ADAPT-01**: Consumer can pass `adapter` option to `createDeepAgentsHandler({ backendUrl, adapter })`. Adapter type is `{ name: string, transforms: SseTransform[] }`. Pipeline becomes `[...adapter.transforms, ...options.transforms]`.
- [x] **ADAPT-02**: `deepagentsAdapter` exported from `@deepagents-nextjs/server` — encapsulates current `defaultTransforms`. Used as default when `adapter` option is omitted. `defaultTransforms` kept as `@deprecated` alias.
- [x] **ADAPT-03**: `langGraphAdapter` exported from `@deepagents-nextjs/server` — normalizes raw LangGraph `astream_events v2` SSE format to AI SDK v6 wire format.
- [x] **ADAPT-04**: `langchainAdapter` exported from `@deepagents-nextjs/server` — normalizes LangChain native SSE format to AI SDK v6 wire format.

### Stream Resilience

- [x] **STR-02**: `createDeepAgentsHandler` accepts optional `retry?: { maxRetries?: number, initialDelayMs?: number }`. On backend connection failure, retries with exponential backoff (default: 3 retries, 100ms initial delay). Mid-stream failures do not retry.
- [ ] **STR-01** *(conditional)*: Stream reconnection via AI SDK `experimental_resume`. Include only if upstream bugs #6502 and #9707 are resolved before v1.2-05 closes. Otherwise deferred to v1.3.

### DX Tools

- [x] **DX-01**: `DEBUG=deepagents:sse` env var causes `@deepagents-nextjs/server` to emit parsed SSE frames to stderr as `[deepagents:sse] frame: ...`. Zero overhead when env var is unset.
- [x] **DX-02**: `createMockDeepAgentsServer()` exported from new `@deepagents-nextjs/test-utils` package. Usable in Vitest/Jest consumer test suites as a drop-in mock backend. Extracted from `apps/example/route.mock.ts`.
- [x] **DX-03**: `useDeepAgentsChat<TData>()` accepts generic type param where `TData extends Record<string, ZodTypeAny>`. Custom `data-*` part schemas in `TData` extend the `Message` union at compile time. Zero-generic call `useDeepAgentsChat({ sessionId, endpoint })` produces identical type to v1.1.

### Auth Helpers

- [x] **AUTH-01**: `getCookieToken(cookieName: string)` exported from `@deepagents-nextjs/server`. Returns a `getToken`-compatible function that reads `request.cookies.get(cookieName)?.value` (synchronous `NextRequest.cookies`, not async `cookies()` from `next/headers`).

### Framework Adapters

- [x] **FWK-01**: `@deepagents-nextjs/sveltekit` — new package. `createDeepAgentsHandler` accepts SvelteKit `RequestEvent`, proxies to backend via same transform pipeline, returns SvelteKit-compatible `Response`. Includes Svelte reactive store exposing `messages`, `status`, `error`. Node runtime only (v1.2).
- [x] **FWK-02**: `@deepagents-nextjs/remix` — new package. `createDeepAgentsHandler` accepts Remix `ActionFunctionArgs`, returns SSE `Response`. `useDeepAgentsChat` built on native `fetch()` + `ReadableStream` reader loop (NOT `useFetcher` — `useFetcher` buffers the full response and cannot stream SSE). Node runtime only (v1.2).

## Out of Scope

| Feature | Reason |
|---------|--------|
| Cloudflare / Deno / Bun adapter support | Deferred to v1.3; runtime compat is non-trivial and unproven |
| Full SvelteKit / Remix example apps | Deferred to v1.3 once adapters are proven via unit tests |
| Vue / Angular framework adapters | Out of current scope; demand unproven |
| WebSocket transport | SSE is the DeepAgents protocol; WebSocket adds complexity for no benefit |
| Chat UI components | Transport + types only — UI is the consumer's responsibility |
