## Tech Debt

### TD-01: FWK-02 requirement text drift (medium priority)

**Phase:** v1.2-05-remix-adapter  
**Item:** REQUIREMENTS.md FWK-02 says "useDeepAgentsChat built on `useFetcher`" — actual implementation uses native `fetch()`.  
**Context:** useFetcher was found incompatible with SSE streaming (buffers full response). Decision documented in STATE.md accumulated context and v1.2-05-VERIFICATION.md. The requirement text was not updated.  
**Fix:** Update FWK-02 description in REQUIREMENTS.md to say "useDeepAgentsChat built on native fetch() + ReadableStream loop (NOT useFetcher — useFetcher buffers full response, cannot stream SSE)."  
**Blocking:** No.

### TD-02: SUMMARY frontmatter sparse (low priority)

**Phase:** All v1.2 phases  
**Item:** `requirements-completed` field unpopulated in most plan SUMMARY.md files. Only 2/16 summaries have this field set.  
**Impact:** The 3-source cross-reference audit has gaps — SUMMARY source is thin. Future audits will rely entirely on VERIFICATION.md + REQUIREMENTS.md checksums.  
**Fix:** Backfill `requirements-completed` in SUMMARYs that cover requirements (plans 02 and 03 in v1.2-01 cover ADAPT-01–04/STR-02; v1.2-02 plans cover DX-01/DX-02/AUTH-01; v1.2-04 plans cover FWK-01).  
**Blocking:** No.

### TD-03: SvelteKit store TypeScript strict-check issue (low priority)

**Phase:** v1.2-04-sveltekit-adapter  
**Item:** `packages/sveltekit/src/store.test.ts` has TypeScript type inference errors under `tsc --noEmit` due to vitest mock typing. All 25 tests pass at runtime.  
**Fix:** Update mock typing in store.test.ts to satisfy strict tsc. Options: cast with `as`, or use `vi.fn<Parameters, ReturnType>()` form.  
**Blocking:** No.

### TD-04: turbo.json missing outputs key (low priority)

**Phase:** v1.2-04 + v1.2-05  
**Item:** `turbo.json` `test` task has no `outputs` entry for the two new packages — causes "no output files found for task @deepagents-nextjs/remix#test" warnings in CI.  
**Fix:** Add `"outputs": []` to test task config in turbo.json (test tasks produce no artifacts).  
**Blocking:** No.
